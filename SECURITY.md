# Security Policy

Security fixes target the current `main` branch of this public portfolio snapshot.

Do not open a public issue for a vulnerability that could expose credentials, private data, authentication material, payment information, or a practical exploit path. Use the contact details on https://vovinhlac.com for private disclosure.

Please include the affected component, reproduction steps, expected/observed behavior, impact, and any suggested mitigation.

This repository intentionally excludes production credentials, customer/order data, uploads, database exports, backups, logs, payment secrets, and site-specific private configuration. If a secret is ever committed, rotate or revoke it before removing it from history.
